# ① 抽证据
python3 scripts/extract_trace.py \
  -i ~/.claude/projects/*/xxx.jsonl -o trace.json

# ② 出文档
python3 scripts/forge.py -t trace.json \
  -n 你的名字 -c C4 --title "任务标题" -o .

# ③ 体检（退出码≠0 就别交）
python3 scripts/health_check.py \
  -f 你的名字_C4_AI日志.md 你的名字_C4_AAR.md \
  -t trace.json -o 体检报告.md

# 没有记录？走访谈模式
python3 scripts/forge.py --interview -n 你的名字 -c C4

6为什么这 20 分差值很关键

rubric 维度分值日志里对应什么本技能怎么保证
AI使用质量20 分多轮迭代 / prompt 优化 / 你做了什么trace.json 硬证据 + 逐轮判断列表
复盘质量20 分失败经验 / 改进方案 / 迭代过程自动捕获失败轮次 + AAR 模板强制填写
红旗：一句话指令无迭代封顶 5 分轮次 < 3 且无修正信号体检单独列红旗 + 退出码 1
红旗：无 AI 使用记录封顶 5 分压根没写日志本技能就是为了解决它
