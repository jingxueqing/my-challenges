# JingXueQing_C4_skill说明 — ai-log-forge（AI 日志 / AAR 锻造器）

> **一句话：输入**一段真实的 AI 协作记录，**输出**一份有数据支撑、能过评审的《AI 使用日志》+《AAR 复盘》+ 交卷前体检报告。

---

## 1. 解决什么问题

### 1.1 痛点：评分最看重的两份东西，恰恰最难写

Elite20 的 20 个挑战里，**几乎每一个都要求交 `*AI日志*`，多数还要求 `*AAR*`**。
按官方 rubric：

| 维度 | 分值 | 实际在问什么 |
|---|---|---|
| AI使用质量 | 20 分 | 多轮迭代？prompt 优化过？你是怎么指挥 AI 的？ |
| 复盘质量 | 20 分 | 有没有失败经验？有没有改进方案？有没有记录迭代过程？ |

**合起来 40 分，全靠这两份文档。** 但人手写它们时会掉进三个坑：

1. **记流水账** —— "我让 AI 帮我写了个脚本，AI 写得不错，我改了一下"。看不出迭代，直接踩中
   「一句话指令直接提交、无迭代」红旗，**该维度封顶 5 分**。
2. **临交卷前编** —— 轮次、工具调用、失败点全靠回忆，编出来的数字经不起追问；更糟的是
   "没失败经验" 会被判为「敷衍了事」。
3. **不知道自己写得够不够** —— 写完就交，没有反馈，下次还是老样子。

### 1.2 本技能的解法：事实交给脚本，叙事交给你

- **脚本抽证据**：轮次、时间戳、工具调用分布、报错轮次、prompt 逐轮改写链——全部来自真实记录，无法伪造。
- **脚本搭骨架**：《AI 日志》《AAR》的表格和数据自动填好，只在需要人判断的地方留 `<!-- LLM-FILL -->` 占位。
- **脚本打分数**：对照评分标准逐维度给分，抓红旗、数占位符，退出码非 0 就不许交。

> 设计信条：**日志里的数字必须是真的，反思才需要人写。**
> 反过来（数字靠编、反思靠套话）恰好是评审一眼识破、直接零分的那种。

## 3. 输入 / 输出

### 输入

| 项 | 说明 | 必需 |
|---|---|---|
| AI 协作记录 | Claude Code 会话 `.jsonl` ／ 对话导出 `.json` ／ 粘贴的 `.md`/`.txt` ／ 含上述文件的目录 | 三选一（没有就用访谈模式） |
| `--name` | 姓名，用于文件命名 | ✅ |
| `--challenge` | 挑战号 / 项目代号 | ✅ |
| `--title` | 一句话任务标题 | ✅ |
| `--profile` | 评分标准 yaml（可选，默认 C4 全套） | ❌ |

### 输出

```
Demo_C4_AI日志.md        一页速览 · 迭代全时间线 · prompt 优化轨迹 · 失败与返工 · 我的贡献 · 产物验证 · 复现命令
Demo_C4_AAR.md           目标/实际/差距 · 失败经验 · 改进方案（带优先级）· 下一步
体检报告.md               逐维度得分 + 红旗警告 + 未填占位符清单 + 按性价比排序的改进建议
trace.json               中间证据（可复核、可复现，任何人拿同一份记录能跑出同样结果）
```

## 4. 使用场景（谁会用它）

| 场景 | 怎么用 |
|---|---|
| 🎓 **交课程作业**（Elite20 全 20 个挑战，每个都要 AI 日志） | 挑战做完 → 跑一遍 → 补写占位符 → 交 |
| 🧑‍💼 **工作周报 / 项目复盘** | 把本周的 AI 会话喂进去，直接产出带数据的复盘 |
| 📄 **论文 / 报告的「AI 使用声明」** | 需要声明"AI 参与程度"时，用 trace 的硬证据说话 |
| 👥 **团队协作规范** | 统一日志格式 + 统一体检标准，新人照着做就不会漏项 |
| 🔁 **自我迭代** | 每次体检分数记下来，看自己是不是真的在进步（而不是自我感觉良好） |

**为什么我认为它会被高频使用**：它不是"锦上添花"的工具，而是**每个挑战的必交项**。
C4 评分第一条是「被使用次数」——一个每次交作业都要用的技能，天然比一个只做一次的脚本更容易被反复使用。

## 5. 使用步骤（3 条命令，30 秒跑通）

```bash
# 0. 安装：把 JingXueQing_C4_ai-log-forge.skill 解压到你的 skills 目录（或直接用源码目录）
tar -xzf JingXueQing_C4_ai-log-forge.skill

# 1. 抽取证据（原始记录 → trace.json）
python3 ai-log-forge/scripts/extract_trace.py \
    --input ~/.claude/projects/<项目>/<会话>.jsonl --out trace.json --markdown

# 2. 锻造文档（trace.json → AI日志 + AAR）
python3 ai-log-forge/scripts/forge.py \
    --trace trace.json --name 你的名字 --challenge C4 --title "任务标题" --out-dir .

# 3. 交卷前体检
python3 ai-log-forge/scripts/health_check.py \
    --files 你的名字_C4_AI日志.md 你的名字_C4_AAR.md --trace trace.json --out 体检报告.md
```

**没有原始记录？** 走访谈模式，回答 8 个问题照样出全套：

```bash
python3 ai-log-forge/scripts/forge.py --interview --name 你的名字 --challenge C4 --out-dir .
```

装了技能后，也可以直接对 AI 说人话：

> "帮我写这次作业的 AI 日志，会话文件在 ~/.claude/projects/x/y.jsonl，我是 JingXueQing，挑战 C4"

## 7. 核心设计

### 7.1 三层分工：谁该干谁干

| 层 | 负责人 | 理由 |
|---|---|---|
| 事实层 | **脚本** | 轮次/工具/报错/prompt 改动——LLM 会编，编了就是零分 |
| 叙事层 | **人 + LLM 补写** | 只有当事人知道为什么这么决策；脚本只标占位，**不代写** |
| 评分层 | **脚本 + yaml** | 数据驱动，换标准不改代码 |

### 7.2 硬证据优先于关键词

给 `--trace` 时，体检用真实数字判定而不是数关键词：
- 轮次 ≥ 3 或 有迭代信号轮次 → 「多轮迭代」命中
- 失败轮次 ≥ 1 → 「含失败经验」命中（这是最值钱的一条）
- prompt 优化链 ≥ 1 → 「prompt优化」命中

### 7.3 红旗机制：先解决封顶项，再谈文采

rubric 里的 red flag 会把整个维度锁死（例如「一句话指令直接提交」→ AI使用质量最高 5 分）。
体检脚本会单独列一节并给出**退出码 1**，可以当提交前的 CI 关卡用。
没填的 `<!-- LLM-FILL -->` 每处扣 1 分（上限 20）——所以"补完占位符"永远是性价比最高的提分动作。

## 8. 真实案例（可直接复现）

**输入**：`samples/demo_session.jsonl` —— 一份 7 轮的 Claude Code 会话样例
（写销售数据汇总脚本：报错 → 粒度错 → dtype 错 → 空值口径 → 权限报错 → 跨年分组错 → 收尾）。

**Step 1 抽取结果**：

```
源文件 1 个 ｜ 轮次 7 ｜ 用户发言 7 ｜ AI 回复 9 ｜ 工具调用 28
工具分布：Edit×12、Bash×10、Write×6
迭代信号轮次：[2, 3, 4, 5, 6]
失败/返工轮次：[2, 4]
prompt 优化链：5 条
```

**Step 2 生成**：`Demo_C4_AI日志.md`（9 KB）+ `Demo_C4_AAR.md`

**Step 3 体检（补写前）**：**80 / 100**（含未填占位符扣分 −20），退出码 1

**Step 4 补写后复检**：**100 / 100**，退出码 0 ✅

完整运行记录见 `samples/demo_run.log`，一键复现 `bash samples/run_all.sh`。
（说明：demo_session.jsonl 是为演示构造的样例夹具，不是我的真实会话——
这样任何人 clone 下来都能跑出完全相同的结果；你换成自己的记录就是真实数据。）

## 9. 边界与已知限制

| 情况 | 表现 | 处理 |
|---|---|---|
| 找不到 / 解析 0 条对话 | 退出码 2 / 3 + 明确提示 | 检查后缀与文件是否为空 |
| 单个源文件损坏 | 打印警告并跳过 | 不中断整体解析 |
| 纯文本没有说话人标记 | 整段被当成同一说话人 | 先加 `我:` / `AI:` 标记 |
| ChatGPT 导出 HTML | 不支持 | 改导出 Markdown / JSON |
| 记录只有 1-2 轮 | 如实生成，体检扣分 | **不伪造轮次** |
| 没装 PyYAML | 内置迷你 YAML 解析器兜底 | 零 pip 依赖 |
