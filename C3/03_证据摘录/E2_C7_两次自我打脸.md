**真实数字是 3，不是 1。**

:::danger 这是本次最重要的一个教训
「只有 1 个」比「只有 3 个」更抓人。
**如果我先写标题再核对，我一定会舍不得改——因为改完之后文章没那么「惨」了。**
所以我现在的顺序是：**先核数，再定标题。**
:::

## 摘录 2：依赖缺失与「不装」的判断（P2 的直接来源）

<!-- JingXueQing_C7_AI日志.md L111-L127 -->
````text
### R4 · 第二次打脸：环境依赖缺失

【实测】按常规用托管版 Python 跑排版技能，直接失败：

```text
$ python3 -c "import markdown, bs4, lxml, pygments, PIL"
ModuleNotFoundError: No module named 'markdown'
```

我没有去 `pip install`（那会污染系统环境，而且 C4B 那次我就在自己的技能里明确禁止了自动装依赖）。

改成先探测哪个环境齐备：

```text
$ ~/.workbuddy/binaries/python/envs/default/bin/python3 -c "import markdown; print('md ok')"
md ok
```
````
