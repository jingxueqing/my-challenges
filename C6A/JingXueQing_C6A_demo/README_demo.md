# demo 说明：不用装任何东西，双击就能看

这个目录是 C6A 的**演示入口**，不是主体交付。

## 打开方式

- 看走查：双击 `demo.html`（浏览器打开，零依赖、不联网）
- 玩真的：打开 `../JingXueQing_C6A_仪表盘/index.html`，可筛选、可排序、可导出

## demo.html 里有什么

7 屏截图走查，按「总览 → 按学生 → 按挑战 → 时间线 → 缺失项 → 方法与口径 → 记录详情」的顺序，
每屏配一句「这屏解决什么问题」。截图来自本机实跑结果，不是设计稿。

## 为什么单独做 demo

因为交互仪表盘要打开一整个目录才好用；demo 是**一根链接就能给评审看的版本**——
评审没时间跑管线，只想 30 秒知道这东西长什么样、能回答什么问题。

数据来源与口径见 `../JingXueQing_C6A_数据说明.md`。
