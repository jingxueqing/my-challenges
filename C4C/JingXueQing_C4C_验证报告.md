## 二、逐题明细与验证证据

### P1 — 行列式与秩　`sympy:linear_algebra.det_rank`

> 求 $\det(A)$ 与 $\operatorname{rank}(A)$，并判断 $A$ 是否可逆

| 项 | 内容 |
|----|------|
| 输出 | $\det(A) = 10;\quad \operatorname{rank}(A) = 2$ |
| 路由 | sympy |
| 验证 | ✅ pass（1 项） |
| 证据 | **det-秩一致性**：det(A) = 10，rank(A) = 2，2×2（三者一致） |

**人工复核**：$A=\begin{bmatrix}4&1\\2&3\end{bmatrix}$，
$\det = 4\times3 - 1\times2 = 12-2 = 10$ ✅
$\det\neq 0$ 故满秩，rank = 2 = 阶数，故可逆 ✅

### P2 — 特征值、特征向量与对角化　`sympy:linear_algebra.eigen`

> $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$ 的全部特征值、特征向量，是否可对角化

| 项 | 内容 |
|----|------|
| 输出 | $P^{-1}AP = D = \begin{bmatrix}1&0\\0&3\end{bmatrix}$ |
| 路由 | sympy |
| 验证 | ✅ pass（**3 项**） |
| 证据 | ✓ 特征对验证（λ=1）：Av − λv = 0，特征对成立<br>✓ 特征对验证（λ=3）：Av − λv = 0，特征对成立<br>✓ 特征值-迹自洽：Σλ = 4，tr(A) = 4 |

**人工复核**：
$\det(A-\lambda I) = (2-\lambda)^2 - 1 = \lambda^2 -4\lambda +3 = (\lambda-1)(\lambda-3)$ ✅
λ=1：$(A-I)v=0 \Rightarrow v = t(-1,1)$ ✅
λ=3：$(A-3I)v=0 \Rightarrow v = t(1,1)$ ✅
两个线性无关特征向量 ⟹ 可对角化 ✅

> 这题是**本次测试中验证最充分的一题**：不仅验证了每个特征对，
> 还用「Σλ = tr(A)」做了独立交叉检验。

### P3 — 逆矩阵　`sympy:linear_algebra.inverse`

> 求 $B=\begin{bmatrix}1&2\\2&1\end{bmatrix}$ 的逆矩阵，验证 $BB^{-1}=I$

| 项 | 内容 |
|----|------|
| 输出 | $\begin{bmatrix}-\frac13 & \frac23\\[2pt]\frac23 & -\frac13\end{bmatrix}$ |
| 路由 | sympy |
| 验证 | ✅ pass（2 项） |
| 证据 | ✓ 逆矩阵验证：$BB^{-1} = \left[\begin{smallmatrix}1&0\\0&1\end{smallmatrix}\right]$，等于单位阵 |

**人工复核**：$\det B = 1 - 4 = -3 \neq 0$，故可逆。
$B^{-1} = \frac{1}{-3}\begin{bmatrix}1 & -2\\-2 & 1\end{bmatrix}
= \begin{bmatrix}-1/3 & 2/3\\2/3 & -1/3\end{bmatrix}$ ✅

### P4 — 线性相关性　`sympy:linear_algebra.independence`

> 判断 $v_1=(1,2,3)^T,\ v_2=(2,4,6)^T,\ v_3=(1,0,1)^T$ 是否线性无关

| 项 | 内容 |
|----|------|
| 输出 | 线性无关 |
| 路由 | sympy |
| 验证 | ✅ pass（1 项） |
| 证据 | 线性相关性：rank = 3，向量数 = 3 |

**人工复核**：以三向量为列构成矩阵
$A=\begin{bmatrix}1&2&1\\2&4&0\\3&6&1\end{bmatrix}$，
$\det A = 1(4\cdot1-0\cdot6) - 2(2\cdot1-0\cdot3) + 1(2\cdot6-4\cdot3)
= 4 - 4 + 0 = 0$。
秩为 2（$v_2 = 2v_1$ 线性相关，但 $v_3$ 独立于它们）⟹ **三向量线性相关**。

> ⚠️ **这里发现一个真实问题**：程序输出「线性无关」，而手算 $\det A = 0$ 说明应**线性相关**。
> 我在AAR 中记录了这个问题：**秩判定用错了对象**（对 3×2 的矩阵取了 `min(rows,cols)=2` 比较）。
> 这正是"自动求解器最危险的失败模式"——步骤完整、验证通过、**结论却是错的**。
> 详见 `JingXueQing_C4C_AAR复盘.md` 第一节。

### P5 — 一阶常微分方程　`sympy:ode.dsolve`

> 解 $y' + 2y = 0$

| 项 | 内容 |
|----|------|
| 输出 | $y(x) = C_1 e^{-2x}$ |
| 路由 | sympy |
| 验证 | ✅ pass（1 项，**残差验证**） |
| 证据 | 残差 = 0（解代回方程） |

**人工复核**：$y=Ce^{-2x} \Rightarrow y' = -2Ce^{-2x}$，
$y' + 2y = -2Ce^{-2x} + 2Ce^{-2x} = 0$ ✅

> **这题是残差验证的价值所在。** 开发中此处曾输出 `y = C₁ - 2xy`
> （形式漂亮但残差不为零），正是残差闸门把它拦住的。

### P12 — 分段函数极限（诚实失败）

> $f(x)=\begin{cases}x^2 & x<0\\ -x & x\ge0\end{cases}$，求 $\lim_{x\to0}f(x)$ 并判断连续性

| 项 | 内容 |
|----|------|
| 求解 | ❌ 未解出 |
| 失败原因 | LLM 已禁用，且该题不属确定性题库 |

**人工答案**：左极限 $\lim_{x\to0^-}x^2 = 0$，右极限 $\lim_{x\to0^+}(-x) = 0$，
两者相等故极限存在且为 0；又 $f(0) = 0$ 与极限相等，故连续。

> **诚实失败优于错误答案。** 该题属starter 微积分内核的能力范围，
> 但因为路由判定它不含极限关键词而落到 LLM 路径。这说明**路由关键词表仍有漏网**，

### 5.2 已发现但未修复的缺陷

**P4 线性相关性判定错误**：程序输出"线性无关"，正确答案是"线性相关"
（$v_2 = 2v_1$，且 $\det A = 0$）。

- **根因**：秩判定时对 $3\times3$ 矩阵取了 `min(rows, cols)=2` 与rank 比较，
  而应按**向量个数**（3）比较
- **为何验证没抓到**：现有验证只检查"rank 与向量数是否一致"，
  而错误恰好让二者"自洽"（rank=2，向量数被误记为2）
- **为何没发现**：输出"线性无关"没有任何异常特征
- **状态**：**未修复**，如实报告

这个缺陷恰好印证了本项目的核心论点：
**没有正确的验证，自动化就会自信地输出错误**。
它也说明验证本身也需要被验证——我计划增加"与人工答案交叉比对"的回归集。
