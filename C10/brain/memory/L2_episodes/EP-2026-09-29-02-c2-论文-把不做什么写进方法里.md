# C2 论文：把「不做什么」写进方法里

## S（Situation）

要交一篇 AI4Math 可靠性的可投稿 LaTeX 论文，硬交付四件：`paper.tex`（可编译）、
`references.bib`（≥8 篇真实一手文献）、`AI协作日志.md`、`七维AAR.md`。
约束：我没有统一模型环境、没有 API 预算、没有预注册方案。

## T（Task）

5 个阶段（D1 选题 / D2 框架 / D3 机制编码 / D4 成文 / D5 核验），
产出一个**可区分、可证伪**的框架，而不是"综述搬运 + 排行榜数字"。

## A（Action）

- 提出 TRACE 五门框架（任务数据溯源 / 推理搜索 / 语义对齐 / 确定性确证 / 评估重放）+ 门控式选择性发布规则 + Boole 不等式残余错误上界。
- 对 18 项研究做机制编码，正文实际引用 **19 篇**一手来源。
- **主动放弃新实验**：没有统一模型和预注册，拼排行榜数字会制造不可比结论 → 改为给出「复现实验协议」。
- 压缩周期时只压缩阶段标签（D1–D5），**不改真实日期**，在日志里显式说明。

## R（Result）

- 编译通过（XeLaTeX + BibTeX），结构完整含图表公式附录；
- 19 篇引用逐条核验，无缺失；
- 缺：没有真实实验数据（这是"协议"不是"结果"）；五日周期被压成单日集中执行。

## ΔR（R̂ − R）

- R̂ = 1.0 ｜ R = 0.85 ｜ **ΔR = +0.15**
- 判定：轻度高估
- 解释：我在 R̂ 里把"四件硬交付"和"论文的说服力"混成了一个数。
  四件硬交付是 1.0 达成了，但"说服力"因为没有实验而降了一档。
  **一个 R̂ 里塞了两个不同量纲的东西，是这次高估的真正来源。**

## 可复用的一句

**R̂ 只能有一个量纲。** 把"交齐了"和"有说服力"分开量，
否则数字看起来达标，读的人仍然不信。
