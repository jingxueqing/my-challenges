# inbox/candidates/ — 候选技能（自动提名，人工裁决）

`kstar.py distill` 会把「同一标签下 ≥3 条 L2 经验、且没有现有 Skill 覆盖」的簇写到这里。
**这里的东西不是 Skill，只是提名。**

## 裁决记录（2026-11-05，第一次 distill）

| 候选 | 结论 | 理由 |
|---|---|---|
| CAND-ai-归因 | 合并进 measure-before-fix v4 | 与现有步骤重叠 80%，避免"两个技能管一件事" |
| CAND-c8 | 拒绝 | `c8` 是项目标签，不是能力标签 |
| CAND-c9 | 拒绝 | 同上；内核已被 3 个现有 Skill 覆盖 |

## 这次 distill 暴露的规则缺陷（待改进，已记入 AAR）

按 tag 聚类会把**项目标签**（c1–c10）和**能力标签**（口径 / 验收 / 调试）混在一起。
3 个候选里 2 个是项目标签 → 命中率 33%。
**下一版**：`distill` 支持 `--exclude-tags projects.yaml`，或按标签在 L1/L2 中的分布自动区分
（项目标签通常集中在同一时间段，能力标签跨月出现）。
