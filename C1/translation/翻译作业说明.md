# C1 翻译作业说明（执行方必须遵守）

> 生成时间：2026-09-27　适用对象：承担批量翻译的执行方（本机 Agent / 任意翻译单元）
> 本文件是翻译环节的唯一口径来源，与 `pipeline/pipeline.py` 的解析逻辑一一对应。

## 1. 目标

把 `sources/` 下的英文课程语料**逐段**译为简体中文，产出可复现、可校验的译文与中英对照产物。

## 2. 输入

- 批次文件：`build/batches/batch-01.md … batch-30.md`（共 **30 个批次 / 473 段 / 560,465 字符 / 约 84,000 英文词**）
- **只处理这 30 个批次文件**：`build/batches/` 曾出现早期实验残留（共 118 个文件），现已清理；`batch` 命令也已改为重新分批前先清空 `batch-*.md`。若目录里出现 `batch-31.md` 及以后的文件，一律忽略并在回报中提出。
- 术语表：`glossary/术语表.json`（51 条术语，含 `keep_en` 与 `banned`）

## 3. 输出

- 写入 `translation/out/batch-NN.md`（每批次一个文件；文件名只用于归档，内容才是依据）
- **每段译文之前必须有一行定位标记**，照抄批次文件里的小节标题，格式：

  ```
  <!-- seg:<文档名>#<三位段号> -->
  ```

  例：小节标题为 `## context-rot#003` → 必须先写 `<!-- seg:context-rot#003 -->`
- 单个输出文件超过约 6000 字符时，可拆成 `batch-NN-a.md` / `batch-NN-b.md`。
  `collect` 会按文档自动合并；**同一段只能出现一次**（重复且不一致会被记为 conflict）。

## 4. 翻译规则

1. **逐段翻译**：不合并段、不拆分段、不总结、不增删内容。
2. **保留 Markdown 结构**：标题层级、列表、代码块、表格、链接 URL 原样保留。
3. **术语**：
   - `keep_en` 的 14 个词保持英文：`MCP`、`Claude Code`、`Codex`、`Copilot`、`Devin`、`Warp`、`SRE`、`SAST`、`DAST`、`OWASP`、`RCE`、`LLM`、`API`、`GitHub`。
   - `terms` 中出现的术语使用术语表指定译法。
4. **禁用词（banned）**：不得写「代理人」（应为「智能体」）；不得用「提示工程」指 prompt（应为「提示词工程」）；不得写「上下文腐烂度」（应为「上下文腐化」）；不得写「机器代码审查」（应为「AI 代码审查」）。
5. **原样保留**：URL、邮箱、命令、代码标识符、文件名、专有版本号。
6. **中文原文段落**（如 `Vibe_Coding_Playbook` 的中文课件）：按原文誊录，不做英译，并在段落开头保留 `## Page N` 页码标记。
7. **识别不清的乱码**：保留原文并在译文处标注「（识别不清）」，**不得编造内容**。
8. **失败即报告**：某段确实无法处理时，跳过该段并在回报中列出 `文档名#段号`，不要写占位译文。
9. **短片段不放过**：≤200 字符的短片段（共 40 个）与长段同等对待，必须译出。覆盖率分母是**全部 473 段**，不存在「免检区」；不译就会被 `verify` 记为未译。
10. **非正文文件照译**：`all_urls`（URL 清单）、`robots`（规则文件）、`README`（索引）等也要逐段译出；URL、路径、`User-agent`、命令等原样保留，只译其中的说明文字。

## 5. 完成后必须运行

```bash
cd <C1 目录>
python3 pipeline/pipeline.py collect
python3 pipeline/pipeline.py assemble
python3 pipeline/pipeline.py verify
```

`verify` 会检查：源文件 SHA-256 是否被改动、逐文档覆盖率、未译段清单、术语未命中清单，并单独列出 `tiny_segments_le200` / `tiny_translated`（短片段统计）。覆盖率分母 = `build/segments.jsonl` 的全部 473 段，与 `batch` 的分批口径完全一致。

## 6. 回报要求

- 每完成一批，回报：**批次号 / 段数 / 写入文件 / 异常**。
- 全部完成后，回报 `verify` 的原始输出（覆盖率、`untranslated_count`、`glossary_unused`）。
- 不要声称「已完成」却不给出 `verify` 输出。
