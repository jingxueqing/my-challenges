## 常见问题

### 这门课面向谁？

本课程面向具备编程经验（相当于 CS111）并希望学习如何借助现代 AI 工具大幅提升软件开发生产力的学生。建议先修 CS221/229，但不强制要求。

### 这门课我会做出什么？

<!-- seg:index#007 -->

学生将完成每周动手作业，内容涵盖 LLM 提示词、MCP 服务端开发、AI IDE 使用、Claude Code 工作流、安全分析、代码审查自动化以及全栈 Web 应用。课程最终以一个展示现代开发实践的期末项目收尾。

### 我们会用到哪些工具？

课程涵盖一系列 AI 开发工具，包括 Claude Code、Warp 终端、Cursor/Windsurf IDE、Semgrep、Graphite 和 Vercel。我们还会使用模型上下文协议（MCP）以及各种 LLM API。

### 成绩如何评定？

成绩依据每周作业、课堂讨论参与度和期末项目评定。具体截止时间见作业日历。
