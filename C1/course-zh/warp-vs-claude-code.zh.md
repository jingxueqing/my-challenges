# Warp 与 Oz 入门

Warp 是一个智能体化开发环境（Agentic Development Environment），它将现代终端与强大的智能体相结合，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz 提供动力——这是一个面向云端智能体的编排平台。

Warp 将现代终端与云端智能体编排平台 Oz 相结合

## Warp

Warp 是你工作的地方——一个为与智能体协作编程而打造的快速、现代的终端。

核心能力：

- 智能体模式切换（Agent Modality）：在用于执行命令的简洁终端与用于多轮智能体工作流的专用对话视图之间切换。
- 现代终端体验：光标移动、基于块的导航、多行编辑、语法高亮和丰富的补全。基于 Rust 构建，性能出色。
- 代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式代码评审体验。
- 编码智能体集成：语音输入、用于操作终端内图片的 @ 选择等功能。兼容 Oz 以及 Claude Code、Codex 等智能体。

## Oz：面向云端智能体的编排平台

Oz 是为 Warp 所有智能功能提供动力的云端智能体编排平台。Oz 旨在大规模协调智能体——理解你的代码库、自主执行任务，并适应你的工作流。Oz 在设计上就是多模型的，让你可以灵活地为每个任务选择最合适的大语言模型。

Oz 有两种运行模式：

### 本地智能体

直接在 Warp 应用中运行，提供实时、交互式的编程辅助。

- 在整个代码库中编写和重构代码
- 调试问题并修复错误
- 运行命令并解读结果
- 规划并执行多步骤任务

本地智能体让你始终保持掌控。你可以审阅变更、在任务执行中途引导智能体，并在操作执行前进行批准。

### 云端智能体

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）上后台运行，实现大规模自动化。

- 触发器（Triggers）：响应来自 Slack、Linear、GitHub 或自定义 webhook 的事件
- 计划任务（Schedules）：运行重复性任务，例如依赖更新或死代码清理
- 并行执行（Parallelism）：跨仓库或跨任务并发运行大量智能体
- 可观测性（Observability）：每次运行都会被追踪、可审计，并可与团队共享

云端智能体非常适合不需要你即时关注的工作，例如拉取请求（PR）评审、问题分拣、例行维护以及由集成驱动的工作流。

## 两者如何协同工作

Warp 与 Oz 在本地和云端开发之间提供统一的体验：

- 同一智能体，随处可用：无论你是在 Warp 中交互式工作，还是在云端运行智能体，使用的都是同一套底层智能体能力。
- 无缝交接：在云端启动一个任务，当你需要亲自上手时可以在 Warp 中于本地接管，而不会丢失进度或上下文。
- 共享上下文：Warp Drive、Rules 和 MCP 服务器在本地与云端智能体之间通用，因此团队的知识和工具始终可用。
- 团队协作：共享智能体会话、审阅智能体的操作，并引导正在运行的任务——无论任务最初是谁发起的。

## 多模型支持

Oz 在设计上就是多模型的。你可以从精心筛选的一流模型中挑选你偏好的大语言模型。

## 隐私与安全

Warp 符合 SOC 2 合规要求，并与所有签约的大语言模型提供商签订了零数据保留（Zero Data Retention）政策。任何客户 AI 数据都不会被保留、存储或用于训练。

Warp 的 AI 功能可以在 设置（Settings）> AI 中全局禁用。
