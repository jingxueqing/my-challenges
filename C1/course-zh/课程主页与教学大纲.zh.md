# CS146S：现代软件开发者（The Modern Software Developer）

**斯坦福大学 ｜ 2025 年秋季 ｜ 讲师：Mihail Eric**

## 课程简介（Course Description）

过去几年，大语言模型为软件开发引入了一场革命性的新范式。传统软件开发生命周期正在被 AI 自动化改造的每一个环节所改变，由此产生一个问题：下一代软件工程师应如何利用这些进展，把生产力提高十倍，并为职业生涯做好准备？

本课程将展示：现代 AI 工具不仅能提升开发者生产力，还能让软件工程走向更广泛的大众（democratize）。我们将说明软件开发已经从"从 0 到 1 写代码"演进为"计划 → 用 AI 生成 → 修改 → 再循环"的迭代式工作流。学生将掌握传统软件工程挑战背后的理论，以及当下正在解决这些挑战的前沿 AI 工具。

通过动手工程任务与来自业界先锋的嘉宾演讲，你将获得 AI 辅助开发、自动化测试、智能文档与安全漏洞检测方面的实战经验。课程结束时，你将清晰地理解如何把最先进的大语言模型整合进复杂开发工作流，并避开常见陷阱。

# 常见问题（FAQ）

**这门课面向谁？**
面向具备编程经验（相当于 CS111）、希望借助现代 AI 工具大幅提升软件开发生产力的学生。建议但不强制要求修过 CS221/229。

**课程中我会构建什么？**
每周完成动手作业，涵盖：大语言模型提示、MCP 服务器开发、AI IDE 使用、Claude Code 工作流、安全分析、代码评审自动化、全栈 Web 应用。课程以展示现代开发实践的期末项目收官。

**会用到哪些工具？**
课程覆盖一系列 AI 开发工具，包括 Claude Code、Warp 终端、Cursor/Windsurf IDE、Semgrep、Graphite 与 Vercel；同时会使用模型上下文协议（MCP）与各类大语言模型 API。

**成绩如何评定？**
基于每周作业、课堂讨论参与度与期末项目。具体截止日期见作业日历。
