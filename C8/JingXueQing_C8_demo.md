## 2. 两分钟：老师真正会问的四个问题

### ① 「C4B 还有谁没交？」

```bash
python3 -m wcm.cli query "C4B 还有谁没交"
```

```text
**C4B（公众号文章生成技能）还差 18 人**，已交 2/20。
未交名单：陈心怡、邓子龙、冯亦然、高宇飞、郭雅琪、何承翰、林一舟、罗欣然、马嘉乐、
         彭心语、邱志伟、孙乐、吴昊天、谢梦琪、徐方雨、杨海森、赵明轩、周嘉懿
挑战要求：主交付物、AI 日志
证据节点：student:wxid_chenxy、student:wxid_dengzl、…
```

**看点在最后两行**：不是"我说他交了"，而是"我按这条路径查出来的"。
每一条回答都带 `evidence`（节点 id）和 `confidence`，老师能自己复核。

### ② 「景雪晴提交了哪些挑战？」

```bash
python3 -m wcm.cli query "景雪晴提交了哪些挑战"
```

回答里姓名是归一化后的——`JingXueQing`、`景雪晴`、`靖雪晴` 指向同一个人（`config/group_config.yaml` 里的 aliases）。

### ③ 「谁最近不活跃？」「谁帮了谁最多？」

```bash
python3 -m wcm.cli query "谁最近不活跃"
python3 -m wcm.cli query "谁帮了谁最多"
```

沉默 → 罗欣然（10 天）、谢梦琪（7 天）；互助 → 按 `MENTORED` 边排。
这两条是**图查询**，不是把消息全扫一遍——问的是"关系"，不是"文本"。

### ④ 「今天该干什么？」

```bash
python3 -m wcm.cli alerts
python3 -m wcm.cli nudge
```

`alerts` 出 17 条，按严重度排；每条都强制带 `依据`（哪几条数据算出来的）+ `建议`（具体做什么）。
`nudge` 把预警变成**能直接粘贴到微信的草稿**（5 条群消息 + 10 条私信），写进 `out/nudges.md`。

**它不会自动发。** 草稿第一行就写着「复制粘贴到微信，自己看一遍再发」。
一个会自动群发催交的工具，老师不敢用第二次。

## 3. 一分钟：第二天早上它还记得昨天

```bash
rm -f /tmp/wcm_fresh.db
python3 -m wcm.cli watch --days 14 --db /tmp/wcm_fresh.db   # 新库：new: 268
python3 -m wcm.cli watch --days 14 --db /tmp/wcm_fresh.db   # 再跑：new: 0
```

这是"增量"的证据：`fetched` 两次都是 268（源端没变），`already_processed` 从 0 涨到 268，
`new` 从 268 落到 0。**重跑不会把同一个学生催两遍**，也不会把同一份提交算两次。

> 交付前我在这里犯过错：一开始直接在生产库上跑了两遍 `watch`，两遍都是 `new: 0`，
> 看着"通过"，其实什么都没证明（库早就被 `run` 写满了）。后来换成空库才验出真结论。

## 5. 三十秒：它是可以被 Agent 调用的，不是只能人肉敲

```bash
ls SKILL.md skills/*/SKILL.md
```

1 个总技能 + 6 个子技能（`wechat-bridge` / `msg-classifier` / `submission-tracker` /
`qa-sink` / `student-profile` / `class-report`），每个都写清"输入什么、输出什么、什么时候不要用"。
Claude / GPT 这类 Agent 读完 `SKILL.md` 就能直接调 `python3 -m wcm.cli query "…"`，
不需要理解内部实现——**这就是"把群变成 Agent 可调用的能力"那句话的落地方式**。
