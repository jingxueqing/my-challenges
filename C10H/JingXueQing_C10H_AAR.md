## 3. 差距的根因（不是「时间不够」这种废话）

### 根因 1：8 GB 内存把模型能力锁死了（影响最大）

Hermes 硬性要求 ≥64k 上下文。64k KV 在 8 GB 机器上会把内存吃穿，于是：

- qwen3:4b 只能跑到 17–25 tok/s，实际不可用；
- gemma4:e2b 能跑，但 4.6B 的参数量决定了它**做不了多步工具编排**——读文件成功却丢了上下文（`I am ready`），cron 里答非所问。

这不是配置问题，是硬件边界。**任何「换 prompt 让它更聪明」的努力，都在跟参数量对抗。**

### 根因 2：我把「官方路径」当成了「唯一路径」

第一次安装失败后我的第一反应是改造官方 installer（尝试 2），又浪费了 15 分钟。仓库里 `setup-hermes.sh` 一开始就躺在那儿。

**这是「照抄教程」的典型症状**：教程给了命令行，我就只认命令行；系统里明明有更合适的入口，我没读。

### 根因 3：想「手动控制参数」，两次都比默认更差

我手写 `context_length: 16384`（被拒）→ 改 65536（换页）。默认自动探测才是最优解。**「显式配置 = 更可控」是错觉**，尤其在硬件紧张时，自动探测比人拍的数靠谱。

### 根因 4：投入产出比判断失误

为修 qwen3 的 blob 花了 40 分钟，最后只拿到一个「它太慢」的结论。这个结论有价值，但**可以先用一句「8 GB 跑不动 64k 的 4B 模型」推断出来**，不必真跑。

### 根因 5：把「链路通」当成了「功能通」

cron 和 webhook 都是「调度/传输层通了，智能层没通」。如果我只看 `succeeded` 就收工，交付物会是假的。**必须在验收口径里把「通」拆成两段：传输通 ≠ 任务达成。**

## 4. 如果重来一次，我会怎么做

1. **装之前先读 `setup-hermes.sh`**，直接走 dev 入口，省 40 分钟。
2. **先把「不可控项」写成表**（无 Key / 8 GB / 慢网），再决定路线；不要边装边发现。
3. **模型选型先做 5 分钟压力测试**：单次 12k prompt 处理耗时 + 是否换页，达标才继续配 Hermes。不达标就换，别硬修。
4. **cron 任务一律用 `--script` 纯脚本模式**跑确定性检查，模型只负责总结。让 4.6B 模型「自由发挥地执行脚本」是本末倒置。
5. **验收口径提前写成 checklist**（传输层 ✓ / 智能层 ✓ 分开打勾），交付前逐项对，避免自我感动。

## 5. 驾驭一个外部 Agent 系统的方法论（这次真正学到的东西）

挑战要的是「系统驾驭能力」，我把过程抽象成五步，下次换个系统也能用：

**① 先找「不碰网络、不碰编译」的入口。**
Hermes 有三个入口（installer / dev setup / docker）。慢网环境下正确答案是第二个。**能跑起来比跑得漂亮重要。**

**② 用「最小闭环」逐层加码。**
一句对话能回 → 加工具 → 加记忆 → 加技能 → 加调度。每层单独验证，坏了立刻知道是哪层。反过来（先配全套再试）一旦报错，变量太多无法定位。

**③ 报错先读「检查了哪些路径」。**
`llama-server binary not found (checked: …)` 这句话直接告诉我它是「找不到二进制」而不是「模型坏了」。**Hermes 的报错质量很高，值得逐字读。**

**④ 区分「配置层错误」和「能力层错误」。**
`provider` 写错、上下文门槛、工具集过宽：配置层，改一个字就好。
模型参数量不够、内存不够：能力层，改配置没用。**把这两类混在一起排查，是最耗时的坑。**

**⑤ 定制放在用户态，不碰源码。**
我所有改动都在 `~/.hermes/`（SOUL/skills/config/cron/webhook）。好处是 `git pull` 永远不冲突，坏处是不能改内核行为——但对「驾驭」而言，用户态已经足够表达 90% 的个性化。

## 6. 三个「反常识」的发现

1. **记忆有上限反而是优点。** 2200 字符逼 agent 做取舍，超限时报错而不是静默截断。无限记忆会让 agent 变成「什么都记、什么都不重要」。
2. **技能是文档，不是代码。** 44 个技能在 prompt 里只占几百 token，因为索引只有 60 字描述、正文按需加载。这让「技能库无限扩张」在工程上成立。
3. **工具越多，小模型越笨。** 21 个 schema 一起上，4.6B 模型会先犹豫再选错；只给 1 个工具集，它反而干脆利落。**能力不足时，减少选项比增加提示有效。**
