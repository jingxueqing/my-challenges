# 演示：技能支持的每一种排版能力

这份文档同时是**测试样本**和**使用说明**。你看到的每个效果都由
`wechat-publisher-pro` 自动生成。

## 1. Callout 提示框

提示框是公众号排版的性价比之王——比引用块更醒目，又不像代码块那么重。

### 四种基础类型

:::note
📘 **note（知识）**：解释概念、补充背景。视觉最轻，适合大量使用。
:::

:::tip 实测：这样写最容易读
💡 **tip（实践）**：可操作的建议、做法的对比。正文里最常用的一类。
:::

:::warn 别在正文里堆代码
⚠️ **warn（注意）**：容易踩的坑、需要注意的限制。用来提醒读者"这里容易出错"。
:::

:::danger 微信会吃掉你的 SVG
🔥 **danger（踩坑）**：亲历过的失败案例。可信度最高的一类内容。
:::

:::key 核心结论先给
⭐ **key（重点）**：全文最想让人记住的一句话。一篇用 1–2 次，多了就不灵了。
:::

## 2. 标题层级与自动编号

`##` 会自动编号，二级标题是主要导航层：

### 二级标题下的三级小节

编号形如 `2.1`。超过两层就该考虑拆篇了——手机屏幕上三级标题已经很难辨认。

## 3. 行内元素

这段文字里有 **加粗**、*斜体*、`行内代码` 和一个[外部链接](https://example.com)。

关键在于：加粗里可以嵌代码，**粗体里还有 `代码` 和 [链接](https://example.com/inside)**，
这些嵌套内容都不会丢失。

## 4. 代码块

标注语言才有语法高亮：

```python
def convert(md_path, out_path, theme="ink"):
    """把 Markdown 转成公众号 HTML。"""
    html = render(md_path, theme=theme)
    audit(html)          # 合规体检
    write(out_path, html)
    return out_path
```

没有语言标注时会降级为纯文本块，但换行和缩进依然完整：

```
这段没有语言标注
    缩进照样保留
        再深一级
```
