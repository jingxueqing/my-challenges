```bash

       "02_发布稿/A1_我做完十六个东西只有三个被看见.html" \
```

```bash

```

预期：`✅ 全部通过（无违规标签 / 无 class / 无外链图）`

### 4.3 结构硬校验（不只信体检器）

```bash
cd 02_发布稿
for f in *.body.html; do
  echo "$f  div=$(grep -o '<div' "$f"|wc -l)  class=$(grep -o 'class=' "$f"|wc -l)"
done
```

预期：`div=0  class=0`（公众号会剥离 class 和 `<style>`，残留即失效）

## 七、三点说明

**① 为什么有 3 篇而不是 2 篇**
挑战要求「至少 2 篇」。第 3 篇是知乎版——同一批素材、不同结构，用来拿「跨平台」这一项加分。
它不是复制粘贴，结构、开头、甚至结论的排布方式都重写了（见 `拿来说明.md` §2）。

**② 为什么数据是空的**
因为发布要扫码。填一个「约 200 阅读」比空着糟得多——空着是缺项，编一个是造假。

**③ 为什么复盘里写了那么多「我错了」**
因为这次的分数主要不在「文章写得好不好」，在「能不能诚实处理自己做不到的部分」。
83 分的自评里，有 6 分就是扣在没发布、没数据上——**扣得不冤**。
