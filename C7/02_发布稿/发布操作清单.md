## 二、发 A1 的五步

### 1. 登录

打开 <https://mp.weixin.qq.com> → 手机扫码 → 左侧「内容管理」→「草稿箱」→ 右上「新建图文」

### 2. 标题（直接复制）

```
我做完 16 个交付物，只有 3 个被别人看见过
```

作者：`JingXueQing`

### 3. 粘贴正文

1. 用浏览器打开 `A1_我做完十六个东西只有三个被看见.body.html`
2. 页面里 `⌘A` → `⌘C`
3. 回到公众号编辑器正文区 → `⌘V`
4. **检查三处**：表格有没有变成图片、提示框底色还在不在、加粗有没有掉

### 4. 封面和摘要

- 封面：上传 `封面_A1.png`
- 摘要（直接复制）：

```
我的桌面有个文件夹叫「挑战的产物」，里面躺着 16 个交付物。真正对外公开过的只有 3 个，公众号发过 1 篇就断了。这篇讲我怎么发现，以及我决定怎么改。
```

- 原创声明：勾选（本文为本人原创）
- 留言：开启

### 5. 预览 → 发布 → 立刻做三件事

1. 手机预览一遍（重点看表格和提示框）
2. 发布
3. **发布后 30 分钟内**：群内发文案（见 `传播设计.md` 第五节）+ 朋友圈发一条

## 四、知乎发 A3

1. 搜索一个真实存在、有热度的问题（如「大学生如何用 AI 做项目」「一个人能做出什么产品」）
2. 用**回答**形式粘贴 `A3_知乎_*.md`（把 Markdown 直接粘进知乎编辑器，表格需要重新调一次）
3. **前 3 行必须是结论**——知乎只展示前几行，第一段决定有没有人点「展开」
4. 发布后回填链接到追踪表

## 五、截图怎么做（这是 C7 硬要求的交付物）

### 5.1 24 小时节点

发布后 **24 小时左右**，公众号后台：

| 截图 | 路径 | 截什么 |
|---|---|---|
| `A1_24h.png` | 内容管理 → 已发表 → 点开文章 → 数据 | 阅读、在看、分享、留言总数 |
| `A1_来源.png` | 数据 → 阅读来源分析 | 会话 / 朋友圈 / 群 / 搜一搜 的占比 |
| `A1_群内评论.png` | 微信群聊 | 群友的真实回复（打码昵称也可） |

### 5.2 7 天节点

同一位置再截一次，命名 `A1_7d.png`、`A2_7d.png`。

### 5.3 存放位置

全部放到 `04_数据截图/` 目录，然后打开 `03_传播方案/数据追踪表.csv` 把对应行填上。

:::warn 关于「数据截图」这一项
**提交时这一项目前是空的**，因为文章还没发布。
我不会用示意图、占位图或估算数字凑数——那等于自己给自己造假。
截图和数字填完之后，这一项才算真正交付。
:::

## 六、发布前后各一次的 30 秒自查

**发布前**

- [ ] 标题在手机上一行放得下（不折行成两截）
- [ ] 首屏第一段 3 行内出现具体的人/事/数字
- [ ] 全文没有「在这个时代」「总而言之」这类句子
- [ ] 每个数字都能在自己的日志里找到出处
- [ ] 结尾有一个低门槛问题
- [ ] 手机预览：表格不横向溢出、提示框底色在

**发布后**

- [ ] 群内文案发了，且说明了「这篇对谁有用」
- [ ] 朋友圈发了（软的，不像广告）
- [ ] 1 小时内自己在留言区置顶一条补充
- [ ] 24 小时内回完全部留言
- [ ] 截图存好，追踪表填好
